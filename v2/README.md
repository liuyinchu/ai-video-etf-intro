# ETF 图鉴 V2：15 只代表产品的长期收益与风险

V2 将重心放在逐只介绍 ETF。全片约 12 分 16 秒，1920×1080、30 fps；15 个产品段落合计约 10 分 23 秒，占全片约 85%。

每只产品用约 39—45 秒说明资产范围、收益来源及长期持有体验，并显示总回报近似曲线、仅价格曲线、回撤曲线、累计总回报、区间年化、最大回撤与对应恢复情况。各产品的样本日期和币种单独标注。

## 图表说明

历史数据来自用户原始 SVG 附件，观察截止日为 2026-10-30。图表采用每只基金在原观察窗口内的实际可用记录，不使用上市前的指数回测或其他基金历史填补。纵轴按各基金范围缩放，横轴显示各自实际样本日期，不能用视觉斜率或不同起点的年化数据直接排名。

彩线使用复权收盘价近似分配再投资总回报，灰线仅表示拆分调整后的价格，红线表示相对样本内此前最高点的回撤。图中的恢复日期对应标出的那次样本最大回撤，不代表每一次回撤的恢复情况。

`prepare-charts.mjs` 独立读取原 SVG 的坐标轴刻度，标定三条矢量轨迹；再与元数据中的起点、终点、区间年化和最大回撤交叉校验。SVG 轨迹保留了原图的绘图简化，不能当作未经简化的全部日频报价重新用于交易计算。基金层面的费用已反映在价格中，个人税费、汇兑成本和通胀没有另行计入。

## 音乐与配音

继续采用 Edge 云希男声（zh-CN-YunxiNeural），语速 +5%、音高 −2 Hz。字幕和画面的重点切换由实际逐词时间戳驱动。

配乐保留节奏和能量，改为 124 BPM、F-sharp minor 的八小节和声推进。减少持续的密集琶音、开镲与高频音色；股票、债券与超短债段落采用不同密度。较强的段落留给开场、段落进入和片尾。讲解期间音乐增益降低，使用约 220 ms 的提前压低和 850 ms 的恢复过渡。

## 复现

所有制作与渲染都在用户指定的远端仓库完成。使用已有 Node 24、Remotion 4.0.541、Chromium 与仓库内现有依赖；没有安装依赖、执行 Python 或改动虚拟环境。两个参考工程继续保持只读。

```bash
cd ~/workspace/dev/ai-video/ai-video-1114-astra/v2
./scripts/run.sh data
./scripts/run.sh audio
./scripts/run.sh check
./scripts/run.sh stills
./scripts/run.sh render
```

本视频仅科普，不构成任何投资建议。历史表现不预示未来收益。
